# Clients workspace redesign

## Current state
- **Status:** COMPLETE — local source implementation and isolated browser acceptance, 2026-10-28. Installed Tauri app not rebuilt or changed.
- **Goal:** make Clients match the existing compact, flat Tasks/Notes design and expose useful client context and actionable work instead of bare counters/lists.
- **Scope:** local Tauri frontend source; isolated browser/component verification only. No production data access, SSH, schema migration, installer, commit or push.
- **Design authority:** `../../UI_RULES.md`; reuse existing shared role classes and token values. Preserve reference pages and unrelated working-tree changes.
- **Acceptance:** compact workspace chrome; searchable Everything client directory with workload and last recorded contact; focused overview with prioritized open work, project summaries/next due date, profile/primary contact, pinned and recent note previews; exact client/project/task/note navigation; responsive layout; English/Turkish copy; existing profile/notes editing, draft recovery and No Client restrictions remain intact.
- **Verification:** focused selector/component regressions, touched-file ESLint, project-wide `npm run typecheck`, design-token checks, and actual-component browser checks with synthetic records at wide/narrow widths and both locales/themes. Packaging/installed Tauri appearance is not part of this source delivery.
- **Key decision:** derive workload from current stores and local client records; no invented revenue, health score, CRM integrations, or new persisted fields. Last contact means a recorded call/meeting, not inferred communication.
- **Result:** searchable client directory; compact toolbar/counters; due-date-ordered open work; project workload/next-date summaries; profile and primary contact; pinned/recent note previews with exact-note navigation. Profile/Notes retain editing, durable drafts, attachments and client-isolation behavior. No schema or data migration.
- **Verification result:** 47 relevant tests PASS (40 component/selector/role regressions + 7 workspace cases), touched-file ESLint PASS, project-wide typecheck PASS, frontend production build PASS, diff whitespace check PASS. Eight actual-component browser layout cases PASS with no horizontal overflow; real browser search/navigation/draft and focus checks PASS.
- **Remaining limits:** one unchanged Projects-sidebar test conflicts with pre-existing sidebar WIP; three global design-token checks fail in pre-existing Notes/Tasks/shell styles outside this redesign. Full `npm run check` is not claimed. Native Tauri/installer acceptance remains unverified and needs separate scope if requested.
- **Next step:** owner visual review of the source redesign; no further implementation action required for the agreed scope.
- **Preservation:** baseline checkout contains substantial unrelated WIP. Existing translation/token changes were preserved by narrow patches; reference screens, persistence adapters, native services and original client data were not changed.
